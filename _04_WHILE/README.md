# Die `while`-Schleife
Legen Sie eine Java-Datei an und bauen Sie folgende Schleifen

## Aufgabe 1: Die Summe der natürlichen Zahlen
**Summieren** Sie die natürlichen Zahlen **bis Hundert**
`1 + 2 + 3 + 4 + 5 + ... + 100`
in einer Schleife auf und geben Sie das Ergebnis aus.

## Aufgabe 2: Tabelle
Gehen Sie die Zahlen von **10 bis 30** durch und geben Sie das **doppelte** der
Zählvariablen aus. Das ganze soll in der Ausgabe aussehen wie eine **Tabelle**.
```
| Zahl | mal Zwei |
|------|----------|
|   10 |       20 |
|   11 |       22 |
|   12 |       24 |
...
|   30 |       60 |
```
Nutzen Sie das Minus `-` und die Pipe `|` (<kbd>AltGr</kbd> + <kbd>></kbd>) für die Umrandung.

**Tipp:** Die ersten zwei Zeilen in der Beispielausgabe gehören **nicht** in die Schleife.

## Aufgabe 3: FizzBuzz
Diese Aufgabe ist eine klassische Programmierübung die hin und wieder
in Vorstellungsgesprächen vorkommt!

Geben Sie die Zahlen 1 bis 50 in der Konsole aus, aber:
- für Zahlen die durch 3 teilbar sind, geben Sie anstelle der Zahl das Wort `Fizz` aus,
- für Zahlen die durch 5 teilbar sind, geben Sie anstelle der Zahl das Wort `Buzz` aus,
- für Zahlen die sowohl durch 3 also auch durch 5 teilbar sind, geben Sie anstelle der Zahl das Wort `FizzBuzz` aus.

Hier ein Beispiel mit den Zahlen 10 bis 16:
```
Buzz
11
Fizz
13
14
FizzBuzz
16
```
